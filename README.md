# GitHub Profile Viewer

A modern, responsive, and visually stunning web application to search and view GitHub user profiles. Built with a focus on premium UI/UX, fluid typography, and performance.

![Desktop Preview](https://via.placeholder.com/1200x600?text=GitHub+Profile+Viewer+Preview) <!-- Replace with actual screenshot link if possible -->

## 🚀 Features

- **Real-time Search**: Fetch profile data directly from the GitHub API.
- **Premium UI**: Glassmorphism effects, smooth animations, and a sleek dark theme.
- **Fully Responsive**: Optimized for mobile, tablet, and desktop using fluid typography (`clamp()`) and adaptive grid layouts.
- **Detailed Stats**: View repository counts, followers, following, and user bio at a glance.
- **Micro-interactions**: Subtle hover effects and entrance animations for a high-end feel.

## 🛠️ Built With

- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, Flexbox, Grid, and Fluid Typography.
- **JavaScript (ES6+)**: Fetch API and DOM manipulation.
- **Font Awesome**: Professional iconography.
